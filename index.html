⚙️ One-Time Firebase Setup

OSSAI uses a free Firebase database so every officer sees live checklist updates. Takes about 5 minutes — only one person needs to do this.

  1. Go to console.firebase.google.com and sign in with a Google account
  2. Click Add Project → name it ossai → disable Google Analytics → Create Project
  3. In the left sidebar, click Firestore Database → Create database → choose Start in test mode → select us-central1 → Enable
  4. Click the ⚙️ gear icon (top-left) → Project settings → scroll to Your apps → click the </> web icon → register app (any nickname) → copy the firebaseConfig shown
  5. Open index.html and replace the placeholder config block near the top of the <script> section with your copied config, then re-deploy to GitHub Pages
// Find this block and replace it: const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT_ID.firebaseapp.com", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_PROJECT_ID.appspot.com", messagingSenderId: "YOUR_SENDER_ID", appId: "YOUR_APP_ID" };

Test mode leaves the database open to anyone who has the URL. Before sharing this site widely, tighten the Firestore security rules.
